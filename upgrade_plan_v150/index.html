    Kế hoạch nâng cấp v1.5.0 — "Hoàn thiện 100% để dùng được"¶

    Ngày lập: 2026-08-25 · Cấu trúc chốt bởi người dùng: 4 Wave ↔ phát hành theo mapping Wave 1+2 → Beta 1, Wave 3 → Beta 2, Wave 4 → Stable "Phát hành chính thức". Làm xong Wave 2 phải DỪNG để người dùng TEST trước khi đóng gói Beta 1. Mỗi Wave gồm các Track, mỗi Track gồm các Phase.

    Quy tắc xuyên suốt (RULE người dùng): 1. Không commit/push khi chưa được duyệt riêng từng lần. 2. Làm đúng tuyệt đối theo chỉ dẫn đã chốt. 3. Nguyên tắc sản phẩm: công nghệ cao · chính xác minh bạch · Việt Nam trên hết · mọi yêu cầu công nghệ cao đều thực hiện không từ chối ([[core-principles]] trong bộ nhớ dự án).

    Tổng quan trạng thái¶

    Wave Bản phát hành Trạng thái
    Wave 1 — Đóng băng nền tảng Beta 1 (gộp với Wave 2) ✅ Kỹ thuật xong trên máy, chưa commit
    Wave 2 — Tính năng hoàn thiện Beta 1 ✅ Kỹ thuật xong trên máy — ĐÃ DỪNG chờ người dùng TEST
    Wave 3 — Feature freeze + xác thực bên ngoài Beta 2 ⏳ Chưa bắt đầu
    Wave 4 — Phát hành chính thức Stable ⏳ Chưa bắt đầu

    Kết quả Wave 1 (2026-08-25)¶

    • Core 259/259 test · App 730/730 · API 31/31 — tất cả xanh.
    • Coverage: core 95,27% (gate 90) · app 80,50% (gate 80) · api 90,94% (gate 90).
    • python tools/verify.py --all: PASS toàn bộ (format, docs, TT15, OpenAPI, version consistency, analyze ×3, test ×3).
    • Phát hiện & sửa 2 bug thật: (1) cờ markdown B5 chưa được truyền qua API chuyển đổi; (2) batch convertAll crash RangeError khi có ≥ 2 tệp.

    Mục tiêu: toàn bộ công việc v1.2.5 đang treo trở thành một bản phát hành sạch.

    Track 1B — Sửa nợ lỗi chính xác¶

    Track 1C — Chuẩn hóa phiên bản & tài liệu¶
