# Vietnamese Braille Converter

![Flutter](https://img.shields.io/badge/Flutter-3.29-blue)
![Dart](https://img.shields.io/badge/Dart-3.11-blue)
![License](https://img.shields.io/badge/License-MIT-green)

Ứng dụng chuyển đổi văn bản tiếng Việt sang chữ Braille Unicode (8-dot, U+2800–U+28FF) và ngược lại.

## ✨ Tính năng

- **Text → Braille:** Chuyển đổi văn bản tiếng Việt với đầy đủ dấu thanh
- **Braille → Text:** Giải mã chữ Braille Unicode về văn bản
- **OCR:** Nhận dạng văn bản từ ảnh chụp
- **Xuất BRF:** Tạo file Braille Ready Format
- **Voice Input:** Nhập liệu bằng giọng nói tiếng Việt
- **Học Braille:** Chế độ học tương tác với quiz
- **Dark Mode:** Giao diện tối cho người khiếm thị
- **Font Size:** Điều chỉnh kích thước chữ (80% - 200%)

## 🚀 Bắt đầu nhanh

```bash
# Clone
git clone https://github.com/ghitatruongle/vietnamese-braille.git
cd vietnamese-braille/viet_braille_app

# Cài đặt
flutter pub get

# Chạy
flutter run
```
